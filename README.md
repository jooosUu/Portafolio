# josÚ — portafolio

Portafolio de josÚ (VJ · 3D · video · videojuegos · realidad mixta). Sitio estático: HTML, CSS y JS con [three.js](https://threejs.org).

- `index.html` · `css/style.css`
- `js/main.js` arranque, idioma, pantalla de carga · `js/psp.js` PSP 3D · `js/screen.js` "josÚ OS" (menú tipo XMB)
- `js/titere.js` el títere de *Encajonado* · `js/sigil.js` sigilos · `js/i18n.js` textos ES/EN
- `js/data.js` **proyectos** (títulos, textos, imágenes, links)
